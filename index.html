점선은 구매가입니다. 표시 구간은 SNKRDUNK에 남아있는 최근 거래 내역 범위로, 카드마다 거래량에 따라 기간이 다릅니다(거래가 활발한 카드는 최근 1~2일치만 조회됨).
데이터 출처: SNKRDUNK(스니커덩크) 각 카드 상세 페이지의 매매이력(売買履歴), PSA10·1장 거래만 집계.
환산 방식: 엔화 거래가 × 환율(자동 조회) × 1.10(관부가세) = 한국에서 실제 구매 시 드는 비용 기준.
갱신 방법: GitHub Actions가 매일 자동으로 스니커덩크를 조회해 data.json을 갱신합니다. Actions 탭에서 수동 실행도 가능합니다.
